# PcsHmi 发布下载

本仓库用于发布 PCS 上位机及边端服务的安装包，不包含工程源代码。

请进入 [Releases](https://github.com/yycchar/PcsHmiRelease/releases) 下载对应产品的发布包，完整解压后使用。

- 调试上位机：PcsHmi.App
- 维护上位机：PcsHmi.StationApp
- 部署上位机：PcsHmi.DeployApp
- 08B 边端服务：PcsHmi.EdgeService

具体版本、运行环境和使用要求以各次 Release 说明为准。
